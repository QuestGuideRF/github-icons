# 🏅 GitHub Значки: Как их получить

Инструкция по получению различных значков (achievements) на GitHub.

---

## 1. 🏃 QUICKDRAW

**Значок за быстрый merge pull request'а**

1. Создай pull request.
2. Сразу же нажми **Merge**.
3. Значок появится автоматически.

---

## 2. 🦈 PULL SHARK

**Значок за merge нескольких pull request'ов**

1. Создай репозиторий.
2. Сделай pull request (из форка или отдельной ветки).
3. Выполни merge этого pull request'а.
4. Повтори несколько раз — значок появится.

---

## 3. 😎 YOLO

**Значок за push напрямую в default branch (без pull request'а)**

1. Открой репозиторий.
2. Отредактируй файл в `main` (или другой ветке по умолчанию).
3. Сохрани изменения напрямую, без pull request'а.
4. Значок появится.

---

## 4. 🤝 PAIR EXTRAORDINAIRE

**Значок за merge pull request'а от коллаборатора**

1. Пригласи пользователя как **collaborator** в свой репозиторий.
2. Коллаборатор делает pull request.
3. Ты выполняешь **Merge** этого pull request'а.
4. Значок появится.

---

## 5. 🧠 GALAXY BRAIN

**Значок за комментарий, отмеченный как решение**

1. Перейди в раздел **Issues** своего репозитория.
2. Оставь комментарий.
3. Отметь его (или попроси кого-то отметить) как **Mark as answer**.
4. Значок появится.

---

## 6. 🌟 STARSTRUCK

**Значок за получение звезды на репозитории**

1. Создай **публичный** репозиторий.
2. Попроси кого-нибудь поставить **звезду (Star)**.
3. Как только звезда будет — значок появится.

---

## 7. ❤️ PUBLIC SPONSOR

**Значок за публичное спонсирование кого-либо**

1. Найди профиль на GitHub с кнопкой **Sponsor**.
2. Нажми **Sponsor** и оформи **публичную** подписку (не приватную).
3. Значок появится.
